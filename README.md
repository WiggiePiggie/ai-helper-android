# Eva AI Helper

Android AI assistant with local language-model inference and automation features.

## Project background

This repository presents custom Java extensions from Eva's Android application recovery project.

The original Kotlin/Gradle project is unavailable. The current recovery build uses preserved Android bytecode and additional Java components. This repository is not yet a standalone buildable Android Studio project.

## Components

- Local AI inference integration
- Smart intent processing
- Guest-message automation
- Encrypted local configuration
- Notification-based reply handling

## Status

Portfolio source review in progress. Features are not all end-to-end verified.

No model weights, APK files, signing keys, passwords or private guest data are included.
